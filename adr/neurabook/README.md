## Konvensi

- Format: [MADR](https://adr.github.io/madr/)
- Nomor ADR tidak pernah di-reuse.
- Status: `Proposed`, `Accepted`, `Rejected`, `Deprecated`, `Superseded by ADR-XXXX`.
- Keputusan baru yang menggantikan ADR lama → update status ADR lama, jangan hapus.
